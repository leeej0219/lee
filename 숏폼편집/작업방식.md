- 전달: 채팅 파일 + GitHub `숏폼편집/완성본/rawNN_vX.mp4` (50MB 이하로 압축: `-crf 20 -maxrate 10M`)

## 원본 받는 법
- 사용자가 GitHub 릴리스 draft로 업로드: 태그 `raw-NN`, 클립은 번호 이름(`01.MOV`…), 나레이션은 `NARR01.mp3`, `NARR02.mp3`… (번호 순서대로 이어붙임)
- 받기: `https://api.github.com/repos/leeej0219/lee/releases` 에서 asset id → `curl -sL -H "Accept: application/octet-stream" .../releases/assets/<id>` → 크기 검증
- 네트워크: YouTube·구글드라이브·드롭박스·허깅페이스 차단 / GitHub·PyPI 가능

## 편집 순서 (raw-01 최종본 기준)
1. **나레이션 공백 제거** — `tools/narr.py <out>/narr NARR01.mp3 NARR02.mp3` (0.12초 이상 공백 → 앞뒤 0.04초만 남김)
2. **받아쓰기** — `pip install sherpa-onnx` + GitHub 모델
   - SenseVoice(단어별 시각): `sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17.tar.bz2` → `tools/asr.py`
   - Whisper turbo(문장 정확도 비교용): `sherpa-onnx-whisper-turbo.tar.bz2` → `tools/asr_whisper.py`
   - 받는 곳: `https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/<파일>`
3. **클립 내용 파악** — 클립마다 썸네일 시트 만들어서 보고 무슨 장면인지 정리
4. **장면 배치 (`cuts.json` + `plan.json`)** — 나레이션 문장/단어 시각에 맞춰 장면 매칭
   - 훅(첫 질문)과 마지막 질문은 같은 장면으로 수미상관
   - 단어 나열 구간은 1초 내외로 빠르게, 보통 1.5~2.5초
   - 카페처럼 긴 클립은 탐색 범위를 넓게(원본 전체) 줘서 좋은 순간 찾기
5. **렌더** — `MODE=dynamic python3 -I tools/render.py <raw폴더> <out>`
   - **dynamic 모드가 기본** (움직임 큰 순간 우선, 블러 제외) — 사용자가 정적인 화면을 지루해함
   - 원래 움직임 없는 컷(음식 등)은 plan 4번째 값으로 천천히 확대(0.10~0.12)
6. **검수** — 0.25~1초 간격 캡처 시트로 흔들림·블러·장면 오매칭 확인 후 수정
7. **자막** — `subs.tsv`(시작초<TAB>문장) 작성 → `tools/mkass.py subs.tsv <길이> subs.ass` → ffmpeg `ass=subs.ass:fontsdir=<폰트폴더>`
   - 스타일: Pretendard Bold 56px, 흰색, 외곽선 3.2 진회색, 그림자 1.5, 가운데, y=1305
   - 문장은 의미 단위로 쪼갬(앞줄은 연결어미로 끝), 15자 이내, 마지막 질문만 2줄
   - 폰트: `https://github.com/orioncactus/pretendard/releases/download/v1.3.9/Pretendard-1.3.9.zip`
   - 음성인식이 불확실한 문구는 사용자에게 확인 요청
