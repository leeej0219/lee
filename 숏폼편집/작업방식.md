# 숏폼 컷편집 작업 방식 (다음 세션용)

## 역할
- Claude: **컷편집만** → 완성본 **MP4** 전달
- 사용자: 자막, BGM 직접 추가
- 스타일 기준: `레퍼런스-스타일가이드.md`

## 원본 받는 법
- GitHub 릴리스 임시저장(draft)로 업로드 (웹 업로드는 파일당 25MB 제한이라 불가, 릴리스는 파일당 2GB)
  - https://github.com/leeej0219/lee/releases/new → 태그 `raw-01`(다음은 `raw-02`…) → 파일 첨부 → **Save draft** (Publish 안 함)
- 클립 파일명 앞에 순서 번호(`01.mp4`, `02.mov`…), 나레이션은 `narration.*`
- 서버에서 받기: `https://api.github.com/repos/leeej0219/lee/releases` 에서 asset id 확인 →
  `curl -sL -H "Accept: application/octet-stream" https://api.github.com/repos/leeej0219/lee/releases/assets/<id>`
- 이 환경 네트워크: YouTube·구글드라이브·드롭박스·허깅페이스 차단 / GitHub(릴리스 포함)·PyPI 가능 → 허깅페이스 모델은 불가. 대신 sherpa-onnx(pip) + GitHub 릴리스의 SenseVoice 모델로 한국어 음성인식 가능 (`tools/asr.py`)

## 편집 기본값
1. 나레이션 말 사이 공백 제거 (자막 사이 빈틈 0초 수준)
2. 클립은 파일 번호 순서대로, 나레이션 끊기는 지점에 맞춰 1.5~2초 컷 (긴 클립은 여러 컷으로 분할), 전환은 하드컷
3. 클립 원래 소리 끔 (사용자가 지정한 번호만 살림)
4. 출력 1080×1920, 30fps MP4, BGM 없음

## 도구
- `tools/subseg.py`: 레퍼런스 영상에서 자막 바뀌는 시점 검출 (`python3 -I subseg.py 영상 0.62 0.73 출력접두어`)
- 레퍼런스 영상은 릴리스 `ref-videos`(draft)에 계속 보관 (R2=default.mp4, R3=-1.mov, R4=_vlog_._.mp4). 다시 분석할 때 여기서 받으면 됨.
- 음성인식 모델 받기: `pip install sherpa-onnx` → `https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17.tar.bz2` (약 1GB) 압축 해제 → `python3 -I tools/asr.py <모델폴더> narr.wav narr.json`
- 편집 순서(개선): 나레이션 받아쓰기 → 문장별로 맞는 장면 배치 → 렌더 → 1초 간격 캡처로 검수
