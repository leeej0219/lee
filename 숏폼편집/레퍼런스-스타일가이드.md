# 숏폼 레퍼런스 스타일 가이드

> 2026-10-16 분석. 레퍼런스 R2·R3·R4 (R1은 업로드 실패로 아직 미분석).
> - R2: 퇴사후 무기력증 극복하기 ep.01 (강릉 혼여, 82초)
> - R3: 퇴사후 무기력증 극복하기 ep.02 (지상군 페스티벌, 53초, 360p 저화질본)
> - R4: 민간인 은지의 군대일지 (합동화력훈련, 60초)
> 수치는 프레임/오디오를 직접 측정한 값. "추정"이라고 쓴 건 확인 필요.

## 1. 한눈에 보는 공식
- 9:16 세로, 1080×1920, 30fps
- **한 화면 = 한 자막 = 한 컷.** 자막이 바뀌는 순간 컷도 같이 바뀌는 경우가 대부분
- 자막 한 줄 **평균 10~11자(공백 제외), 15자 넘기지 않기**, 화면에 **약 1.5초**
- 자막과 자막 사이 **빈틈 0초** (끊김 없이 이어붙임)
- 본문 자막은 깔끔한 고딕체, **농담·속마음·제목은 손글씨체**로 구분
- 마지막 자막은 항상 **시청자에게 던지는 질문** (2줄)

## 2. 자막

### 2-1. 본문 자막 (내레이션)
| 항목 | 값 |
|---|---|
| 폰트 | 굵은 고딕체 (Bold). 정확한 폰트명은 확인 필요 — 프리텐다드/본고딕 Bold 계열로 보임 |
| 색 | 흰색 `#FFFFFF` |
| 외곽선 | 얇은 검정/진갈색 외곽선 + 살짝 그림자 (배경이 밝아도 읽히는 정도) |
| 크기 | 글자 높이 약 45~49px (1080 폭 기준) → 폰트 크기 약 50~52px 추정 |
| 위치 | 가로 가운데 정렬, **세로 위치 화면 위에서 약 67~68%** (y≈1280~1330px) — 일반 자막보다 위쪽, 하단 UI(좋아요·댓글·캡션)에 안 가리는 높이 |
| 줄 수 | 1줄이 기본. 마지막 질문만 2줄 |
| 최대 폭 | 약 650px (화면 폭의 60%) |
| 등장 효과 | 없음 (애니메이션 없이 컷과 함께 바로 바뀜) |
| 따옴표/고유명사 | `<워크엔더스>`, `<오롯이 키트>`처럼 꺾쇠로 감쌈 |

### 2-2. 문장 길이·속도 (측정값)
| | R2 | R3 | R4 | 전체 |
|---|---|---|---|---|
| 자막 개수 | 48 | 32 | 44 | |
| 한 줄 글자수 평균(공백 제외) | 11.9 | 10.9 | 8.7 | **10.5** |
| 최대 | 19 | 22 | 17 | 90%가 15자 이하 |
| 한 자막 노출 시간 평균 | 1.71초 | 1.22초 | 1.35초 | **1.46초** |
| 초당 글자수 | 7.0 | 10.1 | 6.6 | **약 7~8자/초** |

**문장 자르는 규칙**
- 한 문장을 **의미 단위 2~3덩어리로 쪼개서** 자막 여러 개로 나눔
  - 예: "숙소는 제가 평소에 찜꽁해둔" / "<워크엔더스>라는 곳으로 갔어요"
  - 예: "저는 실제 탱크나 무기들을" / "살면서 볼 일이 없었는데"
- 앞 자막은 **연결어미로 끝남** (~는데, ~해서, ~하고, ~이라, ~더니) → 다음 자막을 보게 만드는 장치
- 뒤 자막은 **~요 / ~습니다** 로 맺음 (해요체 기본, 정보·마무리는 습니다체 섞음)
- 나열은 한 단어씩 끊어서 빠르게: "부채" / "모자" / "건빵" / "이온음료" (각 0.5~1초)

### 2-3. 손글씨 자막 (모션/포인트용)
- 폰트: 동글동글한 귀여운 손글씨체 (정확한 폰트명 확인 필요)
- 쓰는 곳:
  1. **시리즈 제목** (첫 1~2초, 화면 상단 약 17% 위치): 연노랑 `#FBFEB2` 글자 + 검정 외곽선. 예) "퇴사후 무기력증 극복하기 / ep.01"
  2. **고정 상단 타이틀** (R4는 영상 내내 표시): 흰 글자 + 강조 단어만 초록 `#59764A`. 예) "민간인 은지의 **군대일지**"
  3. **농담·혼잣말 자막**: 본문 자막 자리에 고딕 대신 손글씨로 바꿔서 표시. 끝에 "ㅎㅎ", "...." 자주 붙음. 예) "제가 포 맞은 거 아닙니다ㅎㅎ"
  4. **작은 말풍선 메모**: 본문 자막 바로 위나 피사체 옆에 작게. 예) "내돈내산", "사진 찍고 시퐁엉...", "여자의 비밀", "탱크조아💚"
  5. **색 강조 속마음**: 보라색 손글씨 + 흰 글로우 + 꽃 이모지 줄줄이 (R3)

## 3. 컷·무음 제거
| | R2 | R3 | R4 |
|---|---|---|---|
| 컷 수 | 41 | 35 | 28 |
| 평균 컷 길이 | 1.94초 | 1.46초 | 2.11초 |

- **평균 1.5~2초마다 컷.** 3초 넘는 컷은 거의 없음 (마지막 질문 장면만 3초 내외)
- 소리 측정: 영상 전체에서 0.15초 이상 조용한 구간(-35dB 이하)이 **거의 없음** → 말 사이 공백을 다 잘라내고, 배경음(BGM으로 추정)이 빈틈을 계속 채움
- 자막 사이 빈틈 0초 → 말과 말 사이 숨 쉬는 구간까지 붙여서 **말이 쉬지 않고 이어지는 느낌**
- 컷 전환은 거의 전부 **하드컷**(효과 없는 바로 넘김)

## 4. 모션그래픽·효과
- **도입 1~2초**: 대표 장면 + 손글씨 시리즈 제목 → 바로 첫 자막
- **동그라미 강조**: 흰색 손그림 원으로 화면 속 대상 표시 + 옆에 손글씨 메모 ("여기서 조종 중!")
- **화살표**: 흰색 손그림 곡선 화살표 + 손글씨 ("난 은지쓰 민간인인디")
- **이모지 스티커**: 초록 하트💚, 꽃🌷🌻🌹🌺 등 — 문장 끝이나 사람 옆에 작게
- **회상/에피소드 컷**: 흑백 + 블러 + 검은 테두리 + 빨간 손글씨(흰 외곽선) — 웃픈 해프닝 강조용 ("어깨빵 당해서 음료 떨어져써여")
- 줌인·흔들기 같은 화면 움직임 효과는 거의 안 씀. 셀카 시점·걸어가는 장면 등 **촬영 자체의 움직임**으로 역동성을 줌

## 5. 이야기 구조 (3편 공통)
1. 훅: 시리즈 제목 + 상황 한 줄 ("퇴사를 하고 무기력증이 찾아왔어요" / "퇴사하고 입대했습니다" → "물론 진짜 입대한 건 아니고요")
2. 자기소개 한 줄 ("저는 친구들 사이에서 유명한 밀덕인데요")
3. 장소·활동을 시간 순서로 빠르게
4. 중간중간 손글씨 농담으로 쉼표
5. 느낀 점 1~2문장
6. 마지막: 시청자에게 질문 (2줄, 3초 가까이 노출) → 댓글 유도
