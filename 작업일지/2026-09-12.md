## 개인 메모장 만들기 (같은 날)

### 요청 내용
- PC가 꺼져 있어도 인터넷만 되면 동작하는 개인 메모장을 만들어달라는 요청.
- 메인 페이지(목록) 외에 하위 페이지 하나 필요.
- 일반적인 메모장 기능 포함, 단 토큰이 많이 드는 복잡한 기능은 미리 물어볼 것.

### 확인/결정 사항
- "PC가 꺼져 있어도 동작"하려면 로컬 저장(localStorage)이 아니라 서버에 저장되는 방식이 필요하다고 판단 → Claude Artifact + DB capability로 구현하기로 함(링크로 어떤 기기에서든 접근 가능).
- 사용자에게 두 가지 질문:
  1. 하위 페이지 용도 → "메모 상세/편집 화면" 선택(추천안).
  2. 마크다운/태그/이미지 첨부 등 추가 기능 여부 → "기본 기능만" 선택(추천안).

### 진행한 작업
- Claude Artifact로 개인 메모장 "종이 한 장" 제작 및 게시.
  - 게시 링크: https://claude.ai/code/artifact/e822bf8f-e6f8-46ad-a9f0-a3c0e5739b52
  - `db` capability 사용 (컬렉션 `notes`: title/content/createdAt/updatedAt).
  - 메인 페이지: 메모 목록(검색, 새 메모, 삭제, 상대시간 표시), 빈 상태 화면.
  - 하위 페이지: 메모 상세/편집 화면(제목·본문 입력, 자동저장(디바운스), 글자 수, 삭제, 목록으로 돌아가기).
  - 내용 없이 나가는 빈 메모는 자동 정리(삭제)하도록 처리.
  - 해시 라우팅(`#/`, `#/note/<id>`)으로 새로고침·재게시에도 화면 상태 유지.
- 디자인: Fraunces(제목) + Work Sans(본문) + IBM Plex Mono(시간/글자수) 조합, 라이트/다크 테마 모두 지원.

### 남은 이슈 / 참고
- 이 아티팩트는 `db` capability를 쓰기 때문에 조직 내부용(로그인한 사용자만 접근)이며 공개 공유는 불가능 — 개인 메모장 용도에는 적합.
