## 그냥 은지 YouTube 대시보드 만들기

### 요청 내용
- 기획안 「그냥은지 YouTube Dashboard (OONGDI)」 전체를 전달받음. 채널명은 **그냥 은지**.
- 기획안을 토대로 유튜브 분석 페이지를 만들어 달라는 요청.

### 결정 사항 (기본값으로 진행, 사용자 확인 필요)
- 호스팅: 기존 메모장과 같은 GitHub Pages(`docs/`) 아래 `docs/youtube/` 에 배치 → `https://leeej0219.github.io/lee/youtube/`.
- 저장: 기획안 32장의 "초기엔 수동 입력" 방침에 맞춰 **브라우저 localStorage** 저장 + JSON 백업 내보내기/불러오기.
  (메모장에서 겪은 외부 익명 저장소 실패를 반복하지 않도록 외부 서비스 의존 없이 시작. 기기 간 동기화는 추후 과제.)
- 기획안의 "콘텐츠 유형"에 Shorts/롱폼(형식)과 브이로그/정보형 등(장르)이 섞여 있어 **형식(Shorts/롱폼)** 과 **유형(브이로그·정보형·리액션·팬콘텐츠·인터뷰·기타)** 두 필드로 분리.
- 성과 데이터는 "날짜별 누적값 스냅샷"으로 저장(기획안 34~35장 '기록의 누적'). 스냅샷 사이 값은 선형 보간해서 일별 조회수·기간 합계를 계산.
- 조회수 추이 그래프는 그래프 자체 기간 탭 대신 상단 전역 기간 필터 하나를 따르도록 통일.
- 처음 열면 예시(샘플) 데이터가 보이고, 배너의 "샘플 지우고 시작하기"로 비울 수 있음. 샘플 숫자는 기획안 예시값을 참고한 가짜 데이터.
